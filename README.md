# NET Player — Landing Page

Landing page estática para o serviço de streaming **NET Player** — Filmes, Séries e TV ao Vivo.

## 🚀 Publicação

Este projeto é um site estático puro (HTML + CSS + JS), sem dependências, pronto para:

- **Abrir localmente:** basta abrir `index.html` no navegador.
- **GitHub Pages:** suba para um repositório e ative GitHub Pages na branch `main` (pasta raiz).

## 📁 Estrutura

```
/
├── index.html          # Página principal (semântica, SEO)
├── css/
│   └── style.css       # Design system completo (CSS Custom Properties)
├── js/
│   └── main.js         # Interatividade (accordion, scroll reveal, etc.)
├── assets/
│   ├── images/         # Ilustrações SVG (inline no HTML)
│   └── icons/          # Ícones (inline no HTML)
└── README.md
```

## 🎨 Design System

- **Paleta:** fundo dark-cinema (#12151C), primária rosa (#F2385A), accent ciano (#4FD8E8)
- **Tipografia:** Poppins (Google Fonts), pesos 400–900
- **Componentes:** botões pílula, cards com rotação, tickets de preço, accordion FAQ
- **Ilustrações:** SVGs line-art inline (rolo de filme, câmera, claquete, óculos 3D, poltrona, megafone)

## 📱 Responsividade

Mobile-first com breakpoints:
- Mobile: < 768px
- Tablet: ≥ 768px
- Desktop: ≥ 1200px

## ⚡ Performance

- Zero dependências externas (exceto Google Fonts)
- SVGs inline (sem requests extras)
- Animações via IntersectionObserver
- CSS Custom Properties para manutenção fácil
